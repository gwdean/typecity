# TypeCity

A conceptual Streamlit app exploring symbolic cities, schemas, and declarative structures.

Built as an experimental portfolio project combining:
- Streamlit
- Python
- CSV-based data
- relational thinking
- conceptual visualization

---

## Features

- Interactive Streamlit interface
- City-based symbolic framework
- CSV/data-driven structures
- Experimental conceptual design
- Early exploration of “Schema City” ideas

---

## Tech Stack

- Python
- Streamlit
- pandas
- Plotly

---

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/typecity.git
cd typecity
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```
